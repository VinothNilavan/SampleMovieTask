# **React Native Landscape App (v0.82.1)**

This project is built using **React Native 0.82.1** and designed entirely for a **landscape-only experience**.
All screens, layouts, and interactions are crafted to feel smooth, wide, and visually consistent across devices.

## 🚀 Getting Started

Clone the repository and navigate into the project folder:

npm install

This will install all required dependencies.

## ▶️ Running the App

Connect your device or start an emulator, then launch the app using your preferred React Native command:

npx react-native run-android

Once the app opens, switch to **landscape mode** to see the UI come alive as intended.

## 📱 Features

* Full landscape-only interface
* Smooth, wide-screen optimized UI
* Built on the stable React Native 0.82.1 stack

## 🧪 Testing

Please test all screens and flows in **landscape orientation** to ensure proper rendering and behavior.
